Home tiles — what each project should communicate

Today every tile says “7 done” — a database stat that answers none of the questions a user actually has on landing. The three variants below populate the tile with the things the user came back to find: what was I doing here, when did I touch it last, and what can I do next. Same data, three visual treatments. Live status, quiet history, and ghost folders all coexist without one dominating.

Variant A · Recommended
Recap card
Each tile is a small recap. Name + recency on one line; the last session's title on a second line so the user sees what they were doing; a primary action chip on the right. Live tiles get a purple accent border. Ghost tiles dim to 66%. No tile is bigger than another — visual emphasis only via colour.

Variant B
Two-line minimalist
No explicit action chip — the whole tile is clickable. Same data as A, just visually tighter: name + recency on line 1, last-session title with a state-pip prefix on line 2. Trades a discoverable action button for density. Better if the user is scanning many projects fast.

Quick comparison. A is most discoverable (visible action chip) — best for a user who comes back after a long break and wants the next step pointed at. B is densest — best if you have many projects and want to scan fast. C reads fastest at a glance — the stripe colour tells you state before you've parsed any text. All three replace "7 done" with information that actually helps the user decide what to do.
