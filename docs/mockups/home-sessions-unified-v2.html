What changes between FULL and COMPACT:
• FULL renders the optional .sr-extra line below the row, indented under the title column, showing inline artifact chips (and potentially a brief recap if available).
• COMPACT skips .sr-extra entirely.
• Nothing else moves. Pip, project, title, RESUME chip, agent, reason, time — all in the same column positions in both views.
• Row click → Inspect (unchanged from today)
• RESUME chip → resume the session (unchanged from today)
What I'd change from the current implementation:
• Nothing in COMPACT. It's the existing table. Don't touch.
• FULL bumps the title to 14.5px / weight 500 — gives the "what was I doing" headline weight without changing layout.
• FULL adds .sr-extra render below each row when the session has artifacts attributed to it. When there are no artifacts (the bottom rows in the FULL column above), the row collapses to look identical to COMPACT — automatic graceful degradation.
• The FULL ↔ COMPACT toggle is the only new control, sitting beside the existing filter chips.
• I'd argue against the [Open] button. The whole row is already a click target → Inspect. Adding a redundant button creates two ways to trigger the same action and clutters the row.
