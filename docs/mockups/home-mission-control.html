Mission control — what should Home look like

The pitch is "Mission control for your agents". A mission control isn't a wall of equal-weight cards — it's a dashboard where whatever needs your attention is loud, recent work is one click away, and there's an obvious way to start something new. The previous mocks (A/B/C) made each tile smarter but still rendered the same flat grid. This mock rethinks the layout itself.

A typical day — you have live work, paused work, and history
Sections only render when they have content. Live and Waiting come first because they need attention. Recent is the quiet long tail — collapsible, one row per project. Start fresh is always there as the explicit "I want to begin something new" path.

What changed vs. the tile grid. The tile-grid Home had every project on equal visual footing, and rendered "7 done" as the headline on each one — a database stat that doesn't help the user decide what to do. This dashboard layout treats attention as the organising principle: live and waiting work float to the top with big action buttons; recent work is a compact list with a per-row Resume; ghost projects mute in but stay visible; an explicit Start fresh CTA exists regardless of state.

Spaces stop being the entry point. You used to need to set up tokinvest / blunderfixer / oyster spaces before you could drill in. Now Home is the entry point and projects are the unit; spaces (when the user creates them) become a filter applied via the breadcrumb pill, not a prerequisite navigation step.
