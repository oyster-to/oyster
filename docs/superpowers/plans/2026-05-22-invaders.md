# INVADERS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a faithful classic Space-Invaders clone as the 10th game in the Oyster Arcade — single-file HTML/canvas game named `INVADERS`, full retro-colour palette, top-10 server-side leaderboard, no new audio assets.

**Architecture:** Single static HTML file at `docs/arcade/invaders/index.html`, mirroring the proven `space-jumper/index.html` shape — `<canvas>` + inline JS + inline styles + shared modules loaded via `<script src="../shared/*.js">`. State is plain module-scope variables; the game loop runs on `requestAnimationFrame` and gates on `Arcade.Pause.isPaused()`. Audio mixes two reused MP3s (explosion + lose) with on-the-fly WebAudio synthesis for shoot/march/UFO. Catalogue and leaderboard worker get one entry each.

**Tech Stack:** Vanilla JS + HTML5 Canvas 2D + WebAudio. Existing shared modules: `pixel-font.css`, `cabinet.css`, `touch.css`, `iframe-host.js`, `audio.js`, `pause.js`, `touch.js`, `leaderboard.js`. Cloudflare Worker (`infra/leaderboard-worker/src/worker.ts`) for server-side leaderboard.

**Spec:** `docs/superpowers/specs/2026-05-22-invaders-design.md`

**Branch + worktree:** Already on `arcade-invaders` in `~/Dev/oyster.worktrees/arcade-invaders`.

**Verification model:** The arcade has no unit-test suite — games are verified by opening the page and playing. Every implementation step ends with a manual-verify checklist (open the file, perform an action, observe an outcome) and a commit. The one piece of code with tooling — the leaderboard worker change — gets a typecheck + lint step.

- [ ] **Step 1: Replace the placeholder draw loop with the real game loop scaffold**

  In the `<script>` block, replace the placeholder `draw()` at the bottom with this game-state + loop scaffold. (Coordinate system: canvas-space pixels. `W` and `H` are set by `resize()` — render relative to them; never hard-code dimensions.)

  ```js
  // ============================================
  // GAME STATE
  // ============================================
  // Logical playfield is internally a fixed 240×280 grid scaled to canvas.
  // Keeps sprite sizes/speeds stable across screen sizes.
  const PF_W = 240, PF_H = 280;
  function pfToCanvas(x, y) {
    // Fit the playfield into the canvas with letterboxing.
    const scale = Math.min(W / PF_W, H / PF_H);
    const dx = (W - PF_W * scale) / 2;
    const dy = (H - PF_H * scale) / 2;
    return [dx + x * scale, dy + y * scale, scale];
  }

  // Run-level state — reset on each new game.
  let running = false;
  let score = 0;
  let lives = 3;
  let wave = 1;

  // Player.
  const PLAYER_Y = PF_H - 24;
  const PLAYER_W = 16;
  const PLAYER_H = 10;
  let player = { x: PF_W / 2 - PLAYER_W / 2, alive: true };

  // Bullets — ONE player bullet on screen at a time. Iconic constraint;
  // do not relax. `null` = no shot in flight.
  let playerBullet = null;        // { x, y } or null
  const BULLET_W = 2, BULLET_H = 6;
  const BULLET_SPEED = 220;       // px/sec, canvas-down-positive in pf coords

  // Invader grid — 5 rows × 11 cols. Each cell is { alive, frame } where
  // frame flips 0/1 each march tick for the shuffle animation.
  const COLS = 11, ROWS = 5;
  const INV_W = 12, INV_H = 8;
  const INV_SPACING_X = 16;        // cell width
  const INV_SPACING_Y = 14;
  // Top-down: row 0 = cyan squid (30 pts), row 1-2 = pink crabs (20),
  // row 3-4 = green octopi (10).
  const ROW_COLOURS = ['#2dd4ff', '#ff3aa1', '#ff3aa1', '#4ade80', '#4ade80'];
  const ROW_POINTS  = [30,        20,        20,        10,        10];

  let grid = null;        // { offsetX, offsetY, dir, cells: 2D array, aliveCount, frame }
  let marchAccumulator = 0;

  function newGrid(waveNum) {
    const cells = [];
    for (let r = 0; r < ROWS; r++) {
      const row = [];
      for (let c = 0; c < COLS; c++) row.push({ alive: true });
      cells.push(row);
    }
    // Each wave starts one row lower than wave 1, capped at 3 rows lower.
    const dropRows = Math.min(3, waveNum - 1);
    return {
      offsetX: 24,
      offsetY: 36 + dropRows * INV_SPACING_Y,
      dir: 1,            // +1 = right, -1 = left
      cells,
      aliveCount: ROWS * COLS,
      frame: 0,
    };
  }

  function startRun() {
    score = 0;
    lives = 3;
    wave = 1;
    player = { x: PF_W / 2 - PLAYER_W / 2, alive: true };
    playerBullet = null;
    grid = newGrid(wave);
    marchAccumulator = 0;
    running = true;
  }

  // Splash dismiss now starts the run too.
  splashEl.addEventListener('pointerdown', startRun, { once: true });
  window.addEventListener('keydown', e => {
    if (running) return;
    if (e.key === 'Escape') return;     // pause/close belongs to shared modules
    startRun();
  });

  // ============================================
  // INPUT
  // ============================================
  const keys = {};
  window.addEventListener('keydown', e => {
    keys[e.key] = true;
    if (['ArrowLeft', 'ArrowRight', ' '].includes(e.key)) e.preventDefault();
  });
  window.addEventListener('keyup', e => keys[e.key] = false);

  // Touch buttons proxy through the same keys[] flags.
  (function () {
    const left  = document.getElementById('tc-left');
    const right = document.getElementById('tc-right');
    const fire  = document.getElementById('tc-fire');
    Arcade.Touch.bind(left,
      () => { keys['ArrowLeft']  = true;  },
      () => { keys['ArrowLeft']  = false; });
    Arcade.Touch.bind(right,
      () => { keys['ArrowRight'] = true;  },
      () => { keys['ArrowRight'] = false; });

    // The 0.7 exponent makes the curve start slow then ramp hard at the end —
    // the classic "uh-oh, three left, going fast" feel.

      BASE_MARCH_INTERVAL * Math.pow(fillRatio, 0.7) * Math.pow(0.9, wave - 1));

    // Find the alive bounding box so reverse triggers on the actual edge.

      if (grid.cells[r][c].alive) { if (c < minC) minC = c; if (c > maxC) maxC = c; }

      grid.dir *= -1;
      grid.offsetY += INV_SPACING_Y;

    }
  ```

  ```js
    for (let y = 0; y < SHIELD_H; y++) {
  ```

  ```js
  // ============================================
  // SYNTH SFX — square-wave blips for the classic 1978 sounds. Reads the
  // Arcade.Audio master volume so the cabinet's SFX slider still applies.
  // ============================================
  const synth = (function () {
    let actx = null;
    function ensure() {
      if (actx) { if (actx.state === 'suspended') actx.resume().catch(()=>{}); return actx; }
      try {
        const Ctx = window.AudioContext || window.webkitAudioContext;
        if (!Ctx) return null;
        actx = new Ctx();
      } catch (_) { return null; }
      return actx;
    }
    function masterVol() {
      return (window.Arcade && Arcade.Audio && Arcade.Audio.getVolume) ? Arcade.Audio.getVolume() : 1;
    }
    function blip(freqStart, freqEnd, durMs, gain, type) {
      const c = ensure(); if (!c) return;
      const v = masterVol() * (gain || 0.25);
      if (v <= 0) return;
      const t = c.currentTime;
      const dur = durMs / 1000;
      const osc = c.createOscillator();
      osc.type = type || 'square';
      osc.frequency.setValueAtTime(freqStart, t);
      osc.frequency.linearRampToValueAtTime(freqEnd, t + dur);
      const g = c.createGain();
      g.gain.setValueAtTime(v, t);
      g.gain.exponentialRampToValueAtTime(0.0001, t + dur);
      osc.connect(g).connect(c.destination);
      osc.start(t);
      osc.stop(t + dur);
    }
    function note(freq, durMs, gain) { blip(freq, freq, durMs, gain, 'square'); }
    function shoot()  { blip(900, 220, 90, 0.22, 'square'); }
    // March heartbeat — four notes cycled E2, D2, C2, B1 (the canonical sequence).
    const MARCH_NOTES = [82.41, 73.42, 65.41, 61.74];
    let marchIdx = 0;
    function march() { note(MARCH_NOTES[marchIdx % 4], 110, 0.20); marchIdx++; }
    function marchReset() { marchIdx = 0; }
    // UFO siren — sine sweep up-down, called repeatedly while UFO on-screen.
    function ufoWarble(t /* 0..1 progress across screen */) {
      const f = 480 + Math.sin(t * Math.PI * 8) * 90;
      blip(f, f, 100, 0.15, 'sine');
    }
    return { ensure, shoot, march, marchReset, ufoWarble };
  })();
  ```

  ```js
  // ============================================
  // INITIALS ENTRY — shown in the game-over overlay when the score qualifies.
  // ============================================
  const LETTERS = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789.-';
  let initialsSlot = 0;
  let initialsLetters = [0, 0, 0];

  function paintInitials() {
    const slots = document.querySelectorAll('#go-initials .go-slot');
    slots.forEach((s, i) => {
      s.textContent = LETTERS[initialsLetters[i]];
      s.classList.toggle('is-active', i === initialsSlot);
    });
  }
  function setFireLabel(mode /* 'fire' | 'select' */) {
    const btn = document.getElementById('tc-fire');
    if (!btn) return;
    btn.textContent = mode === 'select' ? 'SELECT' : 'FIRE';
    btn.setAttribute('aria-label', mode === 'select' ? 'Select / advance' : 'Fire');
  }
  function startInitialsEntry() {
    initialsActive = true;
    initialsSlot = 0;
    initialsLetters = [0, 0, 0];
    document.getElementById('go-prompt').hidden = true;
    document.getElementById('go-initials').hidden = false;
    setFireLabel('select');
    paintInitials();
  }
  function finishInitialsEntry() {
    const initials = initialsLetters.map(i => LETTERS[i]).join('');
    initialsActive = false;
    setFireLabel('fire');
    document.getElementById('go-initials').hidden = true;
    document.getElementById('go-prompt').hidden = false;
    const goHi = document.getElementById('go-hiscore');
    if (goHi) goHi.textContent = `SCORE SAVED · ${initials}`;
    endOverlayInputAllowedAt = performance.now() + 400;
    Arcade.Leaderboard.submit(score, initials).then(res => {
      if (!res.ok) console.warn('leaderboard submit failed:', res.error);
      paintSplashHiScore();
    });
  }
  function initialsAction(action) {
    if (!initialsActive) return false;
    if (action === 'letter-prev') {
      initialsLetters[initialsSlot] = (initialsLetters[initialsSlot] - 1 + LETTERS.length) % LETTERS.length;
    } else if (action === 'letter-next') {
      initialsLetters[initialsSlot] = (initialsLetters[initialsSlot] + 1) % LETTERS.length;
    } else if (action === 'slot-prev') {
      initialsSlot = Math.max(0, initialsSlot - 1);
    } else if (action === 'slot-next' || action === 'advance') {
      if (initialsSlot < 2) initialsSlot++;
      else { finishInitialsEntry(); return true; }
    }
    paintInitials();
    return true;
  }

  // Keyboard during initials entry.
  window.addEventListener('keydown', e => {
    if (!initialsActive) return;
    let action = null;
    if      (e.key === 'ArrowUp')    action = 'letter-prev';
    else if (e.key === 'ArrowDown')  action = 'letter-next';
    else if (e.key === 'ArrowLeft')  action = 'slot-prev';
    else if (e.key === 'ArrowRight') action = 'slot-next';
    else if (e.key === 'Enter' || e.key === ' ') action = 'advance';
    else if (e.key.length === 1) {
      const c = e.key.toUpperCase();
      const idx = LETTERS.indexOf(c);
      if (idx >= 0) {
        initialsLetters[initialsSlot] = idx;
        if (initialsSlot < 2) { initialsSlot++; paintInitials(); }
        else { paintInitials(); finishInitialsEntry(); }
        e.preventDefault(); e.stopPropagation();
        return;
      }
    }
    if (action) { initialsAction(action); e.preventDefault(); e.stopPropagation(); }
  });

  // Tap-a-slot + horizontal-swipe-to-cycle-letters touch UX.
  (function wireInitialsTouch() {
    const slots = document.querySelectorAll('#go-initials .go-slot');
    slots.forEach(s => {
      s.style.cursor = 'pointer';
      s.addEventListener('click', e => {
        if (!initialsActive) return;
        const idx = parseInt(s.dataset.slot, 10);
        if (Number.isInteger(idx) && idx >= 0 && idx <= 2) { initialsSlot = idx; paintInitials(); }
        e.stopPropagation();
      });
    });
    const container = document.getElementById('go-initials');
    if (!container) return;
    let dragStartX = 0, dragStartLetter = 0, dragging = false;
    container.addEventListener('pointerdown', e => {
      if (!initialsActive) return;
      if (e.target && e.target.classList && e.target.classList.contains('go-slot')) return;
      dragStartX = e.clientX; dragStartLetter = initialsLetters[initialsSlot]; dragging = true;
      try { container.setPointerCapture(e.pointerId); } catch (_) {}
    });
    container.addEventListener('pointermove', e => {
      if (!dragging || !initialsActive) return;
      const step = Math.round((e.clientX - dragStartX) / 40);
      const newLetter = ((dragStartLetter + step) % LETTERS.length + LETTERS.length) % LETTERS.length;
      if (newLetter !== initialsLetters[initialsSlot]) {
        initialsLetters[initialsSlot] = newLetter;
        paintInitials();
      }
    });
    const endDrag = () => { dragging = false; };
    container.addEventListener('pointerup', endDrag);
    container.addEventListener('pointercancel', endDrag);
  })();
  ```
